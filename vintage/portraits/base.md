\# Project: Vintage Portrait Collection

\# Design Specification



\## 1. Color Palette (Monochromatic \& Vintage)

/\* Use these hex codes for your CSS variables \*/



--bg-paper: #F2F0EB;       /\* Warm off-white, like old paper \*/

--text-primary: #2B2B2B;   /\* Soft charcoal, not pure black \*/

--text-secondary: #595959; /\* Dark gray for meta data \*/

--border-light: #D1D1D1;   /\* Subtle separators \*/

--border-dark: #8C8C8C;    /\* Stronger lines \*/

--accent-hover: #4A4A4A;   /\* Darker gray for interactions \*/



\## 2. Typography (Google Fonts)

/\* Import these from fonts.google.com \*/



1\. Main Titles (H1, H2)

&nbsp;  Font: 'Playfair Display', serif

&nbsp;  Weights: 400 (Regular), 700 (Bold)

&nbsp;  Usage: Site logo, Page titles, Portrait names



2\. Subheaders (H3, Nav, Labels)

&nbsp;  Font: 'Cinzel', serif

&nbsp;  Weights: 400 (Regular), 600 (Semi-Bold)

&nbsp;  Usage: Navigation, "Year", "Artist" labels



3\. Body Text (p, li, figcaption)

&nbsp;  Font: 'EB Garamond', serif

&nbsp;  Weights: 400 (Regular), 500 (Medium)

&nbsp;  Usage: Descriptions, About text, Footer



\## 3. Layout Guidelines

\- Max Width: 1200px (centered)

\- Grid: Simple CSS Grid or Flexbox for the gallery

\- Images: Grayscale filter by default, slight color on hover (optional)

\- Spacing: Generous whitespace (padding/margin) to feel "museum-like"
